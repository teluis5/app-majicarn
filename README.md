# MajiCarn (マジカン) 🚗💨
**諸経費やランニングコスト（維持費）も含めた車代スマート割り勘Webアプリ**

---

## 🌟 概要
ドライブや旅行での割り勘において、ガソリン代や高速代などの「目に見える実費」だけを精算すると、**車両オーナー（車を出した人）が車検・保険・タイヤ摩耗・オイル交換・減価償却などのランニングコストを一方的に負担する**という不公平が生じがちです。

**MajiCarn（マジカン）** は、以下のコストを誰でも納得できるよう客観的かつ公平に計算し、ドライバー優遇や立替相殺、LINE共有までを1画面で完結できるモダンWebアプリケーションです。

---

## ✨ 主な機能

1. **公平なコスト算出エンジン**:
   - **ガソリン代**: 走行距離 ÷ 実燃費 × ガソリン単価、または給油レシート実費入力
   - **トリップ諸経費**: 高速道路（ETC）代、駐車場代、洗車代、レンタカー代、自由経費追加
   - **車両維持費（ランニングコスト）**:
     - 車種別プリセット（軽自動車 10円/km、普通車 14〜18円/km、ミニバン 22円/km、輸入車 28円/km、カスタム）
     - 年間維持費（車検・保険・税金・消耗品・年間走行距離）からの精密逆算モード
     - 同乗者との分担割合スライダー（0%〜100%）
     - 「なぜ維持費が必要か？」の根拠解説モーダル

2. **柔軟な割り勘・精算エンジン**:
   - メンバー追加・削除・名前変更
   - 車主（オーナー）および運転手（ドライバー）の指定
   - ドライバー優遇（運転手全額無料、50%OFF、定額割引など）
   - 各自の立替額を考慮した「最小送金ルート（誰が誰にいくら送金すれば完了するか）」の自動相殺計算
   - お釣りの煩わしさを解消する端数丸め（100円・500円・10円単位 / 切り上げ・四捨五入）

3. **スムーズな共有と保存**:
   - ワンタップでLINEやチャットに貼り付けられる整形テキスト生成（PayPay送金先メモ対応）
   - コピー成功時の紙吹雪演出
   - 愛車のプロファイル（燃費・車種タイプ・維持費レート）をLocalStorageに保存、次回以降ワンタップ適用

## 🛠 技術スタック
- **フロントエンド**: React 19 + TypeScript + Vite 8
- **スタイリング**: Tailwind CSS v4
- **アイコン**: Lucide React
- **演出**: Canvas Confetti
- **テスト**: Vitest

## 🚀 起動・開発手順

### 開発サーバー起動
```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
